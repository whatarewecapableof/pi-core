# pi-core

Owner: Noah (whatarewecapableof). Installed on his machines and on collaborators' machines as a Pi package.

- Install: `pi install git:github.com/whatarewecapableof/pi-core` (main) or `@stable`.
- Test: `npm test` (Node 22.6+ runs the TypeScript test directly).
- Change `CORE.md` only for general behavior. Anything about one person's tools, accounts, names or preferences goes in that person's `~/.pi/agent/core.local.md`, never here.
- Branches: `main` is what Noah runs. `stable` is what collaborators run; fast-forward it after main has been used for real.
